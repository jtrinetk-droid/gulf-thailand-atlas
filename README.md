# The Gulf Thailand Can't Drill

A satellite atlas of the Thailand–Cambodia Overlapping Claims Area and what it means for Thai energy security.

Final project for *Asian Energy Security*, Schwarzman College, Tsinghua University, 2026. Jira Trinetkamol.

Static site: open `index.html`, or visit the GitHub Pages deployment. Map data: Natural Earth (public domain), Esri World Imagery, NASA GIBS, WRI Global Power Plant Database (CC BY 4.0). Claim lines are reconstructions; see the Method & sources chapter.
